### 5. Reflection (Qualitative)

**What went well today?**

We kept the team momentum going strong for the TryHackMe "Love at First Breach" event! We successfully solved two more web challenges together. First, we cracked "Speed Chatter" by identifying a Python/Flask backend and exploiting an unrestricted profile picture upload to drop a Python script (`app.py`). This gave us a reverse shell straight into the server. Then, we tackled "Cupid’s Matchmaker," where we successfully injected a malicious JavaScript payload into a survey form to execute a Stored Cross-Site Scripting (XSS) attack and steal the admin bot's session cookie. 

**What challenged you?**

Setting up the network connections correctly was a bit tricky today. For the Stored XSS attack, we had to ensure our Netcat listener (`nc -lnvp 8000`) was properly configured to catch the HTTP GET request containing the stolen cookie. For the reverse shell, coordinating the attacker IP and port within the Python payload required careful syntax checking to ensure the server would connect back to us successfully.

**Key learning:**

I gained a lot of practical experience with two classic web vulnerabilities. I learned how deadly an unsecured file upload feature can be—if a server doesn't validate file types, you can simply upload code and force the server to execute it for instant Remote Code Execution (RCE). I also learned how to weaponize Stored XSS. By using the JavaScript `fetch()` API combined with `btoa()` to encode the `document.cookie`, we forced the server's own admin bot to hand its credentials directly to our Netcat listener.
