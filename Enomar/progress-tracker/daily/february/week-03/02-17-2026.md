### 5. Reflection (Qualitative)

**What went well today?**

This was the final day of the "Love at First Breach" event, and the team finished incredibly strong! We tackled an IDOR (Insecure Direct Object Reference) vulnerability in the "Love Letter Lock" challenge simply by manipulating the `?id=` parameter in the URL to read other users' private messages. After that, we successfully crossed over into Cryptography with the "When Hearts Collide" challenge. We used Docker to pull the `fastcoll` image and generated two distinct image files that shared the exact same MD5 hash, bypassing the application's file integrity checks. 

**What challenged you?**

Using Docker from the command line for the `fastcoll` tool was a new experience. Figuring out the exact syntax to map our current local directory to the Docker container's working directory (`-v $PWD:/work`) so it could read our base image and output the colliding files took a bit of trial, error, and documentation reading. 

**Key learning:**

I saw firsthand how trivial Insecure Direct Object Reference (IDOR) vulnerabilities can be to exploit if a backend doesn't properly check user authorization against the requested database objects.  
I also learned that MD5 is fundamentally broken for security purposes. Using tools like `fastcoll`, generating an MD5 hash collision is frighteningly fast and easy, proving that systems relying solely on MD5 for file integrity are entirely insecure.
