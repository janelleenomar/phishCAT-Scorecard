## Weekly Challenges & Lessons

**Biggest challenge this week:**
The most significant hurdle was stepping out of my Forensics comfort zone to tackle Web Exploitation challenges during a live CTF event. It was initially intimidating, and setting up the required tools from scratch (Kali Linux VM, OpenVPN, Burp Suite, GoBuster) required a lot of patience. Additionally, I continued to face a steep learning curve when dealing with raw binary data and Hex Editors (HxD).

**How you overcame it (or plan to):**
I overcame the environment friction by taking the time to properly install and configure Kali Linux locally, completely abandoning clunky Windows GUI workarounds. For the Web Exploitation challenges, I leaned heavily on tutorials to understand the fundamental concepts of request interception and directory enumeration, allowing me to exploit an LFI vulnerability.

**Most valuable lesson learned:**
Having a native Linux environment is an absolute game-changer for speed and stability compared to basic text editors (which crashed on large binary files). I also learned that visual representations can be highly deceptive—SVGs can conceal text that can be highlighted directly in a browser, and black redaction boxes in PDFs often leave the underlying text perfectly intact.

**Adjustment for next week:**
I need to continue refining my local Kali Linux workflow to make it smoother. I plan to explore how the web exploitation concepts I learned this week (like directory traversal and LFI) might overlap with my primary focus on digital forensics, while also preparing to dive deeper into packet analysis and Wireshark.
