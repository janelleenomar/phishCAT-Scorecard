## 5. Reflection (Qualitative)

**What went well today?**
I successfully identified and exploited my first Server-Side Template Injection vulnerability. I learned how to detect if a web application is improperly reflecting input into a template engine by using mathematical payloads like `{{7*7}}`. 



**What challenged you?**
The most difficult part was identifying which template engine was being used (Jinja2 vs. Mako vs. Twig). I had to learn the "decision tree" of payloads to see which syntax the server responded to. 

**Key learning:**
SSTI occurs when user input is embedded into a template without being sanitized. This allows an attacker to execute arbitrary code on the server by accessing the application's underlying objects and functions (like `__mro__` or `__subclasses__` in Python).

**Tomorrow's focus:**
Moving on to more advanced SSTI payloads to achieve Remote Code Execution (RCE) and exploring common bypasses for basic filters.
