**What went well today?**
I tackled "Crack the Gate 1," which focused on bypassing a gateway or entry-level authentication check. I was able to find the vulnerability by analyzing the client-side logic that determined whether the "gate" should open.

**What challenged you?**
The logic was slightly more obfuscated than previous "Inspect" challenges. I had to follow the function calls in the JavaScript to see how it was validating the input against the required "key," rather than just looking for a hardcoded string.

**Key learning:**
"Cracking the gate" often involves understanding the *condition* for success. If the validation is done locally, I can either find the correct input or simply use the Console to trigger the "Success" function directly. It's a reminder that anything happening on the client's machine is under the attacker's full control.
