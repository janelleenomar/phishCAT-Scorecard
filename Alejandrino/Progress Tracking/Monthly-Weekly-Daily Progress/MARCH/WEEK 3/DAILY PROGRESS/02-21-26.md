## 5. Reflection (Qualitative)

**What went well today?**
I focused on two PicoCTF challenges that emphasize thorough code review. For **Includes**, I found parts of the flag hidden separately in the CSS and JavaScript files linked to the HTML. For **Unminify**, I practiced reading through "minified" or squashed code to find hidden logic that was obscured by the lack of formatting.

**What challenged you?**
Reading minified code in **Unminify** was tedious. I had to use a "Prettifier" tool to make the JavaScript readable so I could trace the variables and find the flag buried in the obfuscated mess.

**Key learning:**
"Security through obscurity" is not real security. Even if a developer minifies their code to save space or hide logic, tools can easily reverse that formatting. Always check the linked resources (CSS/JS) in the HTML headers, as flags are often split across multiple files to test a hacker's thoroughness.
